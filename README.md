A single deadpan fortune-cookie line for an AI agent, written by a tiny zero-dependency Node program. It cracks open a cookie, reads the slip, and writes the fortune to `/output/entry.txt` — one line, no network, no fuss.

## Run it

```sh
node main.ts
```
